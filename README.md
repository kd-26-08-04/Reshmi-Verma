## 🌿 Design Aesthetics & Philosophy
- **Strictly Light Medical Aesthetic:** Pristine porcelain white (`#FAFDFB`), soothing sage green (`#2D6A4F`, `#52B788`), healing warm sand/cream (`#FAF7F2`), and serene breath aqua (`#0EA5E9`).

## 🫁 Core Interactive Features

1. **Interactive BOLT (Body Oxygen Level Test) Laboratory:**
   - Post-exhale breath-hold stopwatch with 0.1s precision.
   - Tap-at-first-urge detection with instant score bracket evaluation (`<10s`, `10-19s`, `20-29s`, `30-39s`, `40s+`).
   - Physiological **Bohr Effect** clinical explanation & prescribed breath protocols.

2. **Neuromodulation Guided Breathing Sanctuary:**
   - 4 Clinical Presets: **4-7-8 Somatic Relaxation**, **Box Breathing (4-4-4-4)**, **Coherent Breathing (5-5)**, and **Soma Energizer (2-2)**.
   - Built-in soothing Web Audio API synthesizer (432Hz sine tone & 528Hz crystal chimes) with mute/unmute toggle.
   - Dynamic expanding/contracting breathing flower orb.

3. **60-Second Resting Respiratory Rate Counter:**
   - Live tap tracker for resting breaths per minute (BPM) with autonomic classification.

4. **Vagal Tone Auto-Assessment Calculator:**
   - Multi-factor index combining BOLT score, resting BPM, digestion ease, and stress resilience.

5. **Gut Mucosal Regeneration Matrix (`nutrition.html`):**
   - Tight junctions, *Akkermansia muciniphila*, leaky gut repair, mitochondrial ATP biogenesis, and before-and-after diagnostics.

6. **Interactive Health Resilience Assessment (`assessment.html`):**
   - 5-step clinical questionnaire with instant radar domain score analysis.

7. **Consultation Booking & Intake Flow (`booking.html`):**
   - 3 Service Tiers (*Discovery Call*, *Comprehensive Consultation*, *Follow-up*).
   - Pre-consultation intake questionnaire with automatic prefilling of test scores.
   - Confirmation modal with direct **WhatsApp connection**.

8. **"Ask Eva" AI Health Companion:**
   - Floating assistant drawer answering clinical questions on gut health, breathwork, and booking.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) (or port displayed by Vite) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates optimized, bundled static assets inside the `dist/` folder.
